# Jeu Tux

Un mini-jeu de réflexes en HTML, CSS et JavaScript avec Tux, la mascotte de Linux. Un joueur le déplace pour éviter les taches, tandis que son adversaire essaie de le toucher.

## Jouer

**En ligne :** ouvre [mon portfolio](https://abassekaderbhai-dev.github.io/) et clique sur **Jouer** dans la partie **Jeu Tux**.

**Sur ton ordinateur :** [télécharge le dépôt en ZIP](https://github.com/abassekaderbhai-dev/HTML-CSS-JavaScript/archive/refs/heads/main.zip), décompresse-le puis ouvre le dossier `Jeu-Tux`. Double-clique sur `index.html` pour lancer le jeu dans ton navigateur. Garde les autres fichiers dans le même dossier : le jeu en a besoin.

Choisis un mode et clique sur **Commencer**.

- Déplace Tux avec les flèches du clavier ou les boutons à l'écran.
- En solo, les taches sont lancées automatiquement.
- À deux, le second joueur clique dans la zone pour viser Tux.

La partie dure 30 secondes et les deux scores sont affichés :

- Tux (joueur 1) gagne 2 points à chaque esquive.
- Le tireur (joueur 2 ou IA) gagne 5 points par touche.

Le plus grand score gagne et le résultat s'affiche à la fin, avec une égalité si les scores sont identiques.

Clique sur **Recommencer** pour rejouer avec les deux scores à zéro.

Les images sont incluses dans le dossier. Aucune installation n'est nécessaire.

## Pour la suite
